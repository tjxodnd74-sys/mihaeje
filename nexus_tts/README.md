# 넥서스 TTS 귀 검사기 (2026-11-09)
사용자: "tts 꼬라지 봐라… 못 들으면 끝나냐? 들을 수 있는 프로그램을 설치해서 이런 걸 방지해야지"
→ 사람이 듣기 전에 기계가 먼저 듣고 걸러 냄. **릴스·쇼츠 목소리는 이 검사를 통과해야만 렌더·예약.**

## 설치 (한 번)
pip install --break-system-packages faster-whisper praat-parselmouth onnxruntime soundfile matplotlib
(UTMOS 모델 411MB는 처음 실행 때 huggingface에서 자동 다운로드: TigreGotico/utmos-onnx)

## 사용
python3 tts_check.py --audio 목소리.wav --script 읽는대본.txt --out 리포트폴더
- 목소리.wav = 배경음 섞기 **전** 타입캐스트 음성(줄별 파일이면 ffmpeg concat으로 합쳐서)
- 읽는대본.txt = 한 줄에 한 문장, **소리 나는 대로**(아래 발음 사전 적용한 글)
- 종료코드 0 = 통과 / 1 = 다시 녹음. report.txt·pitch.png를 Read로 꼭 확인.

## 검사 기준
- 발음: whisper가 받아 적은 글자가 대본과 다르면 실패(예: 움짤 → '웅잘', 챗GPT → '체치피티')
- 자연스러움: UTMOS 줄별 3.0 미만(배경음 섞인 파일은 --mixed, 2.6 미만) 실패
- 억양: 줄 피치 폭 4반음 미만 = 한 톤 로봇 → 실패
- 문장 끝: 평서문 끝이 +3반음 넘게 올라가면 / 질문 끝이 처지면 실패
- 속도: 3.2~7.8음절/초 밖이면 실패, 줄 사이 쉼 1초 넘으면 실패

## 실패했을 때 고치는 순서 (최대 3번)
1. 발음 실패 → 그 단어를 바꿈(발음 사전 추가) 후 그 줄만 다시 녹음
2. 한 톤·부자연 → 타입캐스트 그 문장 감정 프리셋·톤(피치)·속도를 바꿔 다시. 그래도 안 되면 문장을 짧게 쪼개거나 다른 캐릭터
3. 끝 올림 → 문장 끝을 마침표로, 감정 '보통/차분'
4. 3번 해도 실패 줄이 남으면 그 편은 예약하지 않고 사용자에게 리포트와 함께 알림
