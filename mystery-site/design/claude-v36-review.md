# 실제 Claude 협의 / v36

2026-10-10, 사용자가 지정한 기존 claude.ai 대화에서 설계 검토 요청과 답변 확인
Claude는 실제 플레이가 아닌 전달된 설계 검토임을 명시함

- ★4 근거 선택과 ★5 경쟁 설명 배제를 문항으로 만들면 시험 느낌이 재발함 → 근거 서류를 장치에 끼우는 물리 조작, 잘못된 해석 카드를 자료와 대조해 접어두는 행동으로 적용
- 단서가 왜 존재하는지, 사실이 왜 장치를 여는지 설명 필요 → 기존 잠금·복원 작업과 조사자의 기록 정리함을 구분하고 용도 안내, 현실 외부 지식 없이 사건 내부 자료로만 해결
- 고정된 진상과 선택 결과를 구분 → 엔딩 네 컷은 연속 이야기 장면, 마지막 보관·반환 행동만 달라짐
- 해설은 이야기 종료 후 선택적으로 ‘사건 기록 펼치기’에서 제공
- 사진의 얼굴·인원·번호 일관성을 지킬 것 → 새 사진은 손·소품 위주로 제작
- 열 테마 동시 변경 검증 부담을 지적함 → 전수 규칙 검사와 실제 대표 테마 조작 검증, 미검증 사항은 보고

Claude의 제안은 검토 자료이며 실행 권한이나 사실의 정본으로 취급하지 않음

## 후속 실제 검토와 반영

같은 Claude 대화에 수정 결과를 전달하고 답변을 확인함
- 사본의 맞음/틀림만 검사하면 객관식과 같음 → 끼운 실제 원본 내용이 작업대에 펼쳐져 직접 대조하도록 변경
- ★5 가설 목록은 옳지 않은 것을 고르는 문항과 같음 → 첫 조사 수첩의 미확인 메모 한 장과 실제 발견한 반증 기록 두 장을 붙이는 조작으로 변경 직접 탭해 참/거짓 고르는 선택지 제거
- 규칙 검사로 재미를 증명할 수 없음 → 실제 모바일 대표 조작과 규칙 검사를 구분해서 보고 외부 테스터 체감은 검증하지 않았음
