# 넥서스 카드뉴스 제작 키트 (@nexus_studio.kr)

## 폴더
- `fonts/` Pretendard (HTML에서 `../fonts/...`)
- `assets/heart.png` 넥서스 펭귄(하트 포즈, 투명 배경) — **마지막 장에 꼭 넣음**
- `assets/logo3d.png` N 로고 — 상단 바 왼쪽
- `example/gem_v2.html` + `gem_cover.png` + `gem_v2_grid.jpg` — 기준 디자인(제미나이 젬→스킬, 10장). **이 수준 이상**으로.
- `render.py` — `python3 render.py <폴더>/cards.html` → 같은 폴더에 `카드01.jpg…`, `grid.jpg`
- `done.md` — 올린 카드뉴스 기록(주제 중복 금지)

## 만드는 법
1. 작업 폴더 `nexus_cards/<YYYY-MM-DD>_<영문slug>/` 를 만들고 `example/gem_v2.html`을 `cards.html`로 복사해 내용만 바꿈(경로 `../fonts`, `../assets` 그대로 동작).
2. 디자인 규칙 (기준: 프롬왓·비기 카드뉴스 퀄리티)
   - 어두운 'NEXUS BRIEF' 스타일: 상단 바 `NEXUS BRIEF · <서비스>` + `FILE 0N/총장수`, 작은 영문 라벨(.lab), 96px 굵은 제목(.h, 핵심어는 .v 보라 / .a 주황), 설명(.s), 상자(.box + .tag).
   - 8~10장: ①표지(주제 캐릭터 그림 + 큰 제목 + NOTICE 같은 도장) ②무슨 일 ③공식 근거(인용·출처) ④누가/언제(일정·조건) ⑤되는 것/안 되는 것 or 비교 ⑥좋아진 점 ⑦**COPY·PASTE 지시문 상자**(바로 따라 쓰는 프롬프트) ⑧주의점 ⑨추가 팁 ⑩CTA(펭귄 heart.png + 말풍선 + "저장·팔로우" + @nexus_studio.kr).
   - 주제마다 **그 주제 전용 캐릭터**를 표지에 씀(예: 젬 주제 → 울면서 짐 싸는 보석 캐릭터). 남의 회사 캐릭터·로고·유명인·남의 사진은 금지 → 주제를 상징하는 사물을 귀여운 3D 캐릭터로 직접 만듦.
   - 빈 공간 없이 글씨·상자를 크게. 한 장에 하나의 메시지.
3. 표지 그림: 아래 ★표지 규칙대로. Higgsfield `generate_image`(gpt_image_2_6, quality high, 4:5 또는 16:9를 위쪽에 배치), 주제 상황이 한눈에 보이는 장면 + 매번 다른 화풍·색감, "no text, no letters, no logos" 명시. 1~2장(약 2~3크레딧). 작업 폴더에 `cover.png`로 저장.
4. `python3 render.py <작업폴더>/cards.html` → `grid.jpg`를 Read로 보고 겹침·빈 공간·오타·잘림을 고쳐 다시 렌더(최대 3회).
5. 글 규칙
   - 금지 표현: 최초·유일·완벽·가장·제일·최고·최대·100%·무조건 (python으로 cards.html·캡션 둘 다 0개 확인)
   - 확인된 사실만. 출처(공식 발표·주요 언론)를 마지막 근거 장 하단과 캡션에 적음. 루머·유출설 금지. 이용 조건(유료·지역·순차 배포) 꼭 밝힘.
   - 해요체, 쉽고 짧게. 키캡 이모지 금지(①②③ 사용).
6. 캡션: 스토리형 — 첫 줄 훅(날짜·숫자) / ①②③ 핵심 / 출처 한 줄 + "이미지는 직접 만든 그림이에요" / 📌 저장 유도 / 해시태그 5~6개(#넥서스 포함, 매번 다른 조합 — 2026-11-10 인스타 제한 경고 뒤 같은 태그 묶음 반복 금지). UTF-8 BOM + CRLF로 `캡션.txt` 저장.


## ★ 표지(1장) 규칙 — 2026-11-08 사용자: "클릭 안 할 것 같음, 글도 별로고 표지도 별로"
안 되는 예: 어두운 보라 배경 + 우는 3D 사물 캐릭터 + "12월부터 챗GPT 한도, 하나로 합쳐요"처럼 사실만 적은 제목 + 작은 부제. (매번 같은 톤·같은 캐릭터 느낌이면 피드에서 묻힘)
잘 되는 예(@biggie_ai·@prompt_what 표지 분석):
- **제목 = 손해·궁금증·숫자로 멈추게**: "AI한테 욕하던 사람들 비상", "영상 30개로 5억뷰", "99% 사용자가 모르는 ○○", "조회수 터지는 클로드 명령어 5가지", "○○가 죽인 영상업계". 사실을 그대로 쓰지 말고 "나한테 무슨 일이 생기나"로 바꿈(단, 내용으로 뒷받침되는 말만, 과장·금지 표현 금지).
- **글씨 크게**: 제목 2~3줄, 115~130px, 화면 아래 40% 안팎. 핵심어 하나만 노랑(#FFD43B). **부제·설명 줄 넣지 않음**(사용자: "이런 것도 별로임, 재밌지도 않아 걍 빼"). 작은 태그(AI 뉴스·AI 꿀팁·AI 공감툰) 하나만.
- **그림 = 한눈에 상황이 보이는 장면**(인물·캐릭터의 감정 + 사건), 매번 다른 화풍(밈 같은 실사 동물, 레트로 포스터, 클레이, 픽셀, 웹툰, 에디토리얼 일러스트 등)과 다른 색감. 직전 3편 표지와 화풍·색이 겹치지 않게. 어두운 보라 단색 배경 반복 금지.
- 그림은 위쪽 55~60%, 아래로 어두운 그라데이션 → 그 위에 큰 제목. 그림 속 빈 말풍선·글자는 덮거나 잘라냄.
- 만들고 나서 휴대폰 크기(가로 360px)로 줄여 보고 "피드에서 멈추나?"를 따져 아니면 다시.
- 기준 예시: `example_comic/` 의 표지(카드01) — 큰 3줄 제목 + 노랑 핵심어 + 위쪽 장면.


## ★ 속장은 MP4 (2026-11-09 사용자: "카드뉴스 표지랑 마지막 장 빼고는 MP4 파일로 만들라 하지 않았음?")
- **표지(1장)·마지막 장 = JPG**, **그 사이 모든 장 = MP4(움직이는 슬라이드)**. 인스타 캐러셀에 사진·영상 섞어서 올림.
- 만드는 법: `python3 render.py <폴더>/cards.html`(JPG 전부 + grid.jpg) → `python3 render_mp4.py <폴더>/cards.html`(2장~끝-1장을 `카드NN.mp4`로, 1080x1350·6초 루프·24fps·무음 오디오). 업로드할 때 속장은 JPG 대신 MP4 사용.
- 움직임은 `motion/motion.css`가 자동으로 넣음(제목 살짝 올라옴, 핵심어 밑줄 쓸기, 상자 순서대로 등장, 태그·COPY 상자 빛, 커서 깜빡임, 화살표 움직임, 배경 빛 이동, 그림 천천히 확대). 주제에 맞게 cards.html에 직접 @keyframes를 더 넣어도 됨(숫자 올라가기, 그래프 차오르기, 채팅 말풍선 차례로 뜨기 등) — **매 편 최소 1장은 그 주제 전용 움직임**.
- **첫 프레임부터 내용이 보여야 함**(빈 화면에서 등장 금지 — 사용자 2026-10-28). 렌더 후 각 MP4의 0초·3초 프레임을 뽑아 Read로 확인.
- 시간: 8장 기준 약 5~8분.

- `createScheduledPost(blogId "7758775")`: providers `[{"network":"instagram"}]`만, `instagramData {"type":"POST","isAiGenerated":true}`, media = URL 순서대로(표지 JPG → 속장 MP4들 → 마지막 JPG), text = 캡션(BOM 없이). 섞인 캐러셀이 오류로 거절되면 그 회차만 속장을 JPG로 바꿔 올리고 알림에 적음.
- **브랜드 7088172(로드로그)는 절대 사용 금지. 기존 예약 수정·삭제 금지. 유튜브·쓰레드 provider 넣지 않음.**

## ★★ 2026-11-14 사용자 결정: 카드뉴스는 '릴스'로 올림 (캐러셀 X)
- 근거(메트리쿨 분석): 캐러셀 9편 도달 1~2명, 릴스 19편 45~330명. 팔로워가 거의 없어서 캐러셀은 안 퍼지고 릴스만 퍼짐. 잘된 릴스는 첫 3초 이탈률 70%대(나머지 85~98%).
- 만드는 법: cards.html(1080x1350 장들, 7~9장)을 평소처럼 만들고 `render.py`로 검수 → `python3 render_reel.py <폴더>/cards.html --hook "<첫 1초 한 줄>" --tag "<AI 뉴스|AI 꿀팁|AI 공감툰>"` → `릴스.mp4`(1080x1920, 약 20~25초, 장마다 움직임+장 바뀔 때 펀치, 합성 배경음) + `릴스_썸네일.jpg` + `릴스_프레임.jpg`(0초·1초·중간·끝 확인용, Read로 꼭 봄).
- **--hook은 표지 제목을 반복하지 말고** 멈추게 하는 다른 한 줄(손해·질문·숫자, 20~26자). 표지의 '넘겨 보기 →' 같은 캐러셀 문구는 빼거나 '끝까지 보세요'로.
- 한 장에 글은 2.8초 안에 읽히는 양만(제목 + 상자 2~3개). 꼭 읽혀야 하는 글은 장 위쪽 70% 안에(아래쪽은 인스타 캡션이 덮음).
- 올리기: Higgsfield 업로드(릴스.mp4 video, 릴스_썸네일.jpg image) → `createScheduledPost` instagramData `{"type":"REEL","showReelOnFeed":true,"isAiGenerated":true}`, media=[mp4], videoThumbnailUrl=썸네일.
- ★ 사용자 합의(11/14): **팔로워가 1,000명을 넘으면 캐러셀 카드뉴스를 다시 섞음.** 분석 단계에서 팔로워(IGEV01)가 1,000 이상이면 PushNotification "넥서스 팔로워 <n>명 — 캐러셀 카드뉴스 다시 섞을 때예요(주 2~3편 제안)"을 한 번 보내고, 사용자 OK 전까지는 릴스로 계속.
- 캡션에 "7번째 장" 같은 장 번호 대신 "영상 멈추고 보세요", "저장해 두고 따라 해 보세요".
