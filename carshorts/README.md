# 새 자동차 쇼츠 (로드로그와 다른 채널)

## 형식 1: "OO, 돈 낼 만할까?" 구매 고민 Q&A (레퍼런스: 알카파츠 "휠이 커지면 뭐가 좋을까?")
- 70~90초, 3D 만화 캐릭터 1명(노란 후드·동그란 안경) + 실사풍 SUV(로고 없음), 1~3초마다 컷.
- 공식 숫자로 계산 → 비유 그래픽 1개(코드) → 장단점 → "이런 사람은 A / 저런 사람은 B" → 한 줄 결론.
- 자막: 아래쪽 흰 글씨+검은 테두리, 6~12자 구절. 목소리: 타입캐스트 PC 사이트(서현, 1.2배, 문장마다 문단 → "문장 별로 나누기" 다운로드). 힉스필드 TTS 금지.
- 금지 표현: 최초·유일·완벽·가장·제일·최고·최대·100%·무조건. 숫자는 제조사·오피넷 등 공식 출처만.

## 만드는 순서 (예: 20261109_hybrid)
1. 숫자 조사 → `make_spec.py`의 D(자막, / 로 구절 나눔)와 SH(컷·그래픽) 작성
2. 이미지: nano_banana_2_1 9:16 1k, image_references = 캐릭터(07716a5d-dc22-4f89-9144-03db42dc6434) + 차(d2b326d6-c875-4023-9eec-da144831d38c)
3. 움직임 필요한 컷만 kling3_0 4초 std sound off (6크레딧), `clips/cNN.webm`으로 변환(VP9)
4. 나레이션 zip → `narr/` → `python3 join.py` (narr.wav, times.json)
5. `python3 make_spec.py` → `node ../engine/render.js .` (video_silent.mp4, 약 10분)
6. `python3 mix.py` (나레이션 -15 LUFS, 배경음 -31 LUFS, 효과음) → ffmpeg로 합치기
- 1편 크레딧: 이미지 17장 ≈ 25 + 영상 8개 = 48 → 약 73
