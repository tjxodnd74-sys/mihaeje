# 주제 대기열 (3D + 필재, 30~40초) — 11/24 개편
태웅 11/24: "지금 형식은 조회수도 안 나오고 주제도 재미없고" / "주제가 쾅쾅쾅 이어서 너무 반복적"
→ **사고(쾅) 오프닝은 4편에 1편까지.** 나머지는 사고 없이 '내 차·내 운전에서 매일 겪는 것'. 시작 유형을 매번 바꿈.
- 시작 유형: 실수(웃긴 장면) / 궁금증("이거 뭐예요?") / 문제 해결("여기서 어떻게?") / 돈·벌점 / 사고(쾅, 4편에 1번)
- 직전 2편과 같은 시작 유형·같은 장소(고속도로 등)는 피함. 순서대로 하되 겹치면 다음 줄.
- 숫자·규칙은 만들 때 공식 출처(법령·경찰청·도로교통공단·제조사 취급설명서·정책브리핑·소방청)로 다시 확인. 못 찾으면 그 줄 보류.
