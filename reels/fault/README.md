# 로드로그 릴스 양식: 3D 애니메이션 + 자극적 시작 (2026-11-19~)

## 태웅이 정한 방향 (최우선)
- "양식을 좀 바꾸라고, 계속 100대인데"(11/19) → 정보형(AI 목소리 설명·스톡 클립·법규 퀴즈) 중단.
- "그치 저렇게, 보기 쉽게 해야 돼"(11/19, 우회전 편을 보고) → 넓은 화면, 한눈에 보이게.
- **"몇 대 몇 형식으로 하라는 게 아니라, 저렇게 애니메이션을 이용해야 한다고, 자극적으로 시작하고 자극적인 내용 들어가게끔"(11/19 22:00)**
  → 고정 형식은 '몇 대 몇'이 아니라 **3D 애니메이션 + 첫 0.5초 자극 + 내용도 자극적**. 몇 대 몇은 여러 유형 중 하나.

## 매 편 공통
- 3D(three.js + Kenney Car Kit CC0). 나레이션 없음(글씨+효과음) → isAiGenerated false. 12~20초.
- **0~0.5초: 가장 센 장면부터** — 쾅·미끄러짐·튕겨 나감·아슬아슬하게 비껴감 + 번쩍임·흔들림·파편·폭발음. 설명·인사·빈 화면으로 시작 금지.
- **첫 글씨 = 손해·결과·충격 숫자**: "2초 졸면 56m를 눈 감고 달림", "문 벌컥 열다 쾅", "이거 하면 범칙금 ○만 원". 원인보다 결과 먼저.
- 가운데: 느린 다시 보기 / 숫자 커지기(속도·거리·금액) / 비교(이렇게 vs 이렇게)로 '왜 그런지'를 화면으로.
- 끝: 반전·정답·숫자 한 방 + 의견 갈리는 질문 하나(댓글 유도). 출처 한 줄.
- 보기 쉽게: 장면 전체와 차 움직임이 한 화면에, 글씨 한두 줄 크게(위 250~600px, 아래 1300px 근처; 아래 20%·오른쪽 끝 피함).
- 자극적이어도 **사실만**: 숫자는 공식 출처(경찰청·도로교통공단·한국도로공사·손해보험협회·법령) 또는 직접 계산(속도×시간 등). 금지어(최초·유일·완벽·가장·제일·최고·최대·100%·무조건) 금지.
- 사람이 다치는 모습은 직접 보여주지 않음(인스타가 폭력 장면으로 노출 줄임) — 차·물건 파손, 아슬아슬함, 숫자로 충격.

## 유형 (돌아가며, 성과 좋은 유형 비중 늘림)
1. **사고 재현 → 결과 숫자**: 블랙아이스 연쇄 추돌, 고속도로 갓길 2차 사고, 졸음운전, 문 열다 쾅(도어링), 대형차 사각지대 등.
2. **숫자로 보는 충격(계산)**: "시속 100km로 2초 = 56m", 제동거리 비교(50 vs 100km/h), 빗길·눈길 미끄러짐 거리.
3. **몇 대 몇?(과실 퀴즈)**: `cases.md` — 손해보험협회 기본 과실만, 정답은 캡션에 안 씀.
4. **이거 하면 돈 나감**: 위반 장면 재현 → 카메라 번쩍 → 범칙금·벌점 숫자 쾅(도로교통법 시행령 별표).
- 주제 목록은 `topics.md`(대기 맨 위부터, 끝나면 [완료 날짜]).

## 만들기
- 준비: `bash reels/fault/setup.sh` (Kenney GLB는 `reels/fault/glb/`, CC0).
- web 폴더에 장면 html(fault.html 복사해 장소·경로·카메라를 그 사고에 맞게 새로 짬) + spec.json → `node render.js spec.json silent.mp4` (약 3.5분, 전역 `require('playwright')`) → `python3 mix.py`.
- 오버레이(글씨·A/B 표시·신호 패널·번쩍임·흔들림)와 `window.seek(t)` 구조는 유지.
