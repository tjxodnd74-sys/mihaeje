## 매 편 구성 (샘플: 20261121_3d_2nd_crash, 고속도로 2차 사고 '비트밖스')
1. **0~1초 콜드 오픈**: 가장 센 장면(쾅·미끄러짐)부터 + 번쩍임·흔들림·파편·폭발음 + 위쪽 큰 글씨 한두 줄(손해·결과). 나레이션은 1초쯤부터.
2. **첫 문장 = 결과**: "~하면 이렇게 됩니다" → 그 장면을 느린 다시 보기(위에서 넓게, 위험 구역 빨간 표시).
3. **왜 위험한지 + 숫자 한 방**: 다른 각도(뒤차 시점 등) 재현 → 공식 숫자 크게(출처 작은 글씨).
4. **상식 설명**: 할 일 3~5개를 한 장면씩. 위쪽에 진행 막대(현재 항목 노랑), 항목 이름 크게, 3D 장면이 그 행동을 실제로 보여줌(비상등 깜빡, 트렁크 열림, 사람이 가드레일 밖으로 등).
5. **끝**: 기억할 한 줄 + 요약(항목 다시 한 줄) + 출처. 질문·퀴즈·"댓글로 찍어봐" 금지.
- 자막: 아래쪽(1330px) 한 줄, faster-whisper 단어 시각에 맞춤. 위 큰 글씨는 250~600px.
- 사람이 다치는 모습은 직접 보여주지 않음(위험 구역·빈자리로 표현). 사람 모형은 안전 행동 장면에만.
- 숫자는 공식 출처(한국도로공사·경찰청·도로교통공단·정책브리핑·법령). 출처마다 숫자가 다르면 가장 작은 값 기준("5배 넘게").
- `isAiGenerated: true` (필재 = AI 음성).

## 필재 나레이션 (타입캐스트)
- 새 타입캐스트 studio.typecast.ai(크롬, 로그인돼 있음) → 내 스튜디오에서 최근 `릴스_` 프로젝트 ⋮ → 사본 만들기 → 열기(목소리 필재 유지).
- 본문 클릭 → ctrl+a → Backspace → 새 대본 입력(한 단락). 속도 1.1. 제목 `릴스_<슬러그>`.
- 다운로드: 전체, wav, 한 파일로 합치기 → 약 300크레딧. 파일은 Downloads에 `릴스_<슬러그>.wav`로 받아짐 → device_stage_files.
- 숫자는 한글로 풀어 씀(일오팔팔 다시 이오공사, 다섯 배). 대본 9~12문장, 존댓말, 끝맺음 섞기.

## 만들기
- `bash reels/fault/setup.sh` → web 폴더. 장면 html은 `scene_2nd.html`을 복사해 장소·차 경로·카메라·구간(spec.t)을 새 주제에 맞게.
- spec: page, total, narrOffset(1.0), 구간 시작 시각 t[], text, caps([단어 시작, 자막, 끝]).
- `node render.js spec.json silent.mp4`(37초 약 10분) → `python3 mix2.py`(나레이션 + 효과음 + car_bed 0.12, loudnorm -14).
- 스틸 확인(구간마다 1장): 글씨 잘림·태그 화면 밖·물체 크기·카메라에 장면이 다 들어오는지.
