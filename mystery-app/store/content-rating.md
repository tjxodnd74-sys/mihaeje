# 콘텐츠 등급 설문(IARC) 예상 답

플레이 콘솔 → 앱 콘텐츠 → 콘텐츠 등급 설문에 넣을 답 초안입니다
근거는 2026/11/22 기준 `mystery-site/web/v2/episodes/*.js` 10편 본문과 `web/v2/engine.css` 효과를 직접 읽고 확인한 것입니다

## 결론 먼저

- 카테고리: **게임**
- 체크할 항목: **공포(Fear) 하나만 '예'**, 나머지(폭력·성·언어·약물·도박·사용자 상호작용 등)는 전부 '아니요'
- 예상 등급(확정은 설문 결과가 정함): 한국 GRAC **전체이용가 또는 12세**, PEGI **7**, ESRB **E10+** 안팎

## 항목별 답과 근거

| 설문 항목 | 답 | 근거 |
|---|---|---|
| 폭력 (사람·동물·판타지 대상, 피, 신체 훼손) | 아니요 | 10편 어디에도 싸움·다침·피 묘사 없음 정비소는 SD카드 분실 추리(알리바이 대조)로 폭력 없는 사건 `칼`은 재킷 '칼라', 승강장 '칼로 오린 네컷사진' 정도 |
| 공포 (어린이를 놀라게 할 수 있는 요소) | **예** | 승강장·404호·방송·세탁소 4편이 `mood: 'horror'` (engine.css: 화면 테두리 어둡게 + 11초마다 짧게 흐려지는 깜빡임, 동작 줄이기 설정이면 꺼짐) |
| ㄴ 공포의 정도 | 약함 · 분위기 위주 | 밤 장면, 빈 건물, '404호 귀신' 소문, 혼자 켜지는 스피커, 빈 통으로 도는 건조기 → 모두 끝에 사람이 한 일로 풀림 (초자연 존재가 실제로 나오지 않음) 갑자기 튀어나오는 장면·비명·시체·피 없음 |
| ㄴ 깜빡임 | 있음(짧고 약함) | 공포 4편 무대 깜빡임, 승강장 안내판 글자판이 처음 열릴 때 1.9초 흐려졌다 켜짐 (`st-flash`), 404호 CCTV 화면 켜짐 효과 빠른 번쩍임 반복은 없음 |
| 성적 내용·노출 | 아니요 | 해당 내용 없음 |
| 욕설·비속어 | 아니요 | 본문 전체 검색으로 욕설 없음 확인 (할머니 문자의 오타·띄어쓰기는 말투일 뿐) |
| 약물·술·담배 | 아니요 | 술·담배 언급 없음 `약`은 오행당 약차, 사진관 현상 약품, 동물병원 진료 맥락뿐 |
| 도박·모의 도박 | 아니요 | 없음 오행당의 생년월일 풀이(사주·오행)는 이야기 장치이며 돈·확률·내기 없음 |
| 저속한 유머 | 아니요 | 없음 |
| 죽음·상실 같은 무거운 주제 | 언급 수준 | 사진관: 필름을 맡긴 손님(윤서 씨 아버지)이 세상을 떠났다는 한 줄, 방송: 선배가 목소리를 잃은 이야기, 세탁소: 엄마의 손목 수술 묘사·장면 없음 (IARC에 별도 질문이 있으면 '묘사 없음 · 언급만') |
| 사용자끼리 소통(채팅·게시판) | 아니요 | 없음 「의견 남기기」는 운영자에게만 가는 한 방향 양식 |
| 위치 공유 | 아니요 | 위치 권한·위치 정보 사용 없음 |
| 디지털 상품 구매(인앱 결제) | 아니요 | 현재 없음 (유료 편·결제를 붙이면 다시 답해야 함) |
| 제한 없는 웹 탐색 | 아니요 | 앱 안에서 임의 주소로 갈 수 있는 기능 없음 (개인정보처리방침의 기관·정책 링크만 있음) |
| 개인정보 수집 | 4번 '의견 남기기'만 | 의견 글과 선택 연락처 → `data-safety.md` 참고 |

## 타깃층(앱 콘텐츠 → 타깃층 및 콘텐츠) 제안

- 대상 연령: **13~15세, 16~17세, 18세 이상** 선택 (13세 미만 포함하지 않음)
  - 13세 미만을 넣으면 가족 정책(Families) 심사 대상이 되어 광고·데이터 요건이 더 까다로워짐
  - 글 위주 추리·공포 분위기 편이 있어 어린이 대상 앱으로 보이지 않게 하는 편이 맞음
- '아동의 관심을 끌 수 있는 앱인가' → 아니요 (그림체가 실사·어두운 톤, 글 읽기 위주)

## 다시 답해야 하는 경우

- 유료 편·인앱 결제·광고를 붙일 때
- 새 편에 폭력·사망 장면, 갑자기 놀라게 하는 연출을 넣을 때
- 사용자끼리 기록·댓글을 나누는 기능을 붙일 때
